# Diabetes Prediction Dashboard 🩺📊

A web-based interactive machine learning dashboard built with **Python**, **Streamlit**, and **scikit-learn** to predict diabetes risk and generate professional PDF reports.

## Features
- **Interactive Input:** Easily input patient medical metrics via a clean sidebar.
- **Machine Learning Prediction:** Uses a trained Random Forest model to assess risk levels.
- **PDF Report Generation:** Built-in `reportlab` integration allowing users to download a formal summary report.

## Tech Stack
- **Frontend/UI:** Streamlit
- **Machine Learning:** scikit-learn, pandas, numpy
- **Reporting:** reportlab
